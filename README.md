# Nuti Health
AI Nutrition & Meal Planning Mobile App built with Flutter.

## Features
- AI Meal Recommendation
- BMI & Calories Tracking
- Weight Tracking
- Responsive UI
- REST API Integration

## Tech Stack
Flutter, Spring Boot, PostgreSQL, Gemini AI
